# Газулька | Работа

MVP Telegram-бота для цифрового регламента сотрудников точки аренды электровелосипедов.

## Что работает

- старт рабочей смены;
- последовательный чек-лист открытия из 8 шагов;
- обязательная фотография после уборки крыльца;
- фиксация проблемы на любом шаге;
- рабочее меню после открытия смены;
- базовое закрытие смены.

## Локальный запуск

1. Установить Python 3.11+.
2. Создать виртуальное окружение.
3. Установить зависимости: `pip install -r requirements.txt`.
4. Скопировать `.env.example` в `.env`.
5. В `.env` записать токен BotFather в `TELEGRAM_BOT_TOKEN`.
6. Запустить: `python bot.py`.

Никогда не коммитьте `.env` или Telegram bot token в GitHub.
